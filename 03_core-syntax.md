## CORE SYNTAX

### Comments

```nadesiko
# Single line comment
// Also works
/*
   Multi-line
   comment
*/
```

### Variables

Three ways to assign variables:

```nadesiko
# Standard assignment
variable = 10

# Japanese particle style
variable は 10

# Explicit assignment
10 を variable に代入
```

**Variable naming rules:**

- Can use Japanese, English, numbers (not at start), emoji
- CANNOT use particles (を、に、の、から、へ, etc.) as variable names
- Case-sensitive

### Output

```nadesiko
# Display in console/browser
「Hello World」と表示
「Hello」を表示

# Function-style call
表示(「Hello」)
```
